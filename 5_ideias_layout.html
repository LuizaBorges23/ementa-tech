Experiência Imersiva em Camadas

Hero Bottom-Sheet & Acesso Rápido

Mobile First / Avançado
Ementa Tech Ajuda / Suporte
Acessar

Estrutura de Elementos:

Layout inteligente adaptado para priorizar a ergonomia. Header discreto no topo com branding básico, e uma barra de acesso rápido ancorada na base da tela ("Bottom Action Bar"), facilitando o toque em smartphones e mantendo o espaço central limpo para exibições institucionais.

Prós
  • • Ergonomia perfeita para dispositivos móveis
  • • Menor esforço físico do polegar para login
  • • Layout contemporâneo estilo Web App
Contras
  • • Menos tradicional em desktops
  • • Requer reeducação visual do usuário
